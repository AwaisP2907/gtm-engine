How this was built, and its limits

Signals: Adzuna job-postings API, US + Canada, last 30 days, searched for material handler, warehouse associate, forklift operator, order picker, and automation / robotics / controls engineer. Staffing agencies, robotics vendors, consultancies and IT "automation" roles are filtered out.

Stack: Python (signals, AI scoring, HubSpot sync), Clay (firmographics + buyer contacts), Claude API (fit score, tier, brief, first lines, reply classification), HubSpot (system of record, batch upserts on unique keys), Make (routing + reply handling with error alerts to Slack), Instantly (sequencing + reply webhook), DuckDB + SQL (these numbers).

Limits: one 30-day snapshot; posting counts may include duplicate listings; Brava is a fictional seller, so outreach went only to test inboxes the builder owns; large enterprises dominate because ranking is by posting volume.
